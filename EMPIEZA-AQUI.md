## Abrir el proyecto

Sistema publicado: https://cerebro-nyc-taller.dorisot.chatgpt.site/

1. Instala Node.js 24 LTS.
2. Abre una terminal en esta carpeta.
3. Ejecuta `npm ci`.
4. Ejecuta `npm run verify`.
5. Ejecuta `npm run dev` y abre la dirección local que aparece.

En Windows también se puede usar `INICIAR-WINDOWS.bat`. Los datos de la entrega ya están incluidos y no se necesita contraseña, llave paga ni tarjeta de crédito.
